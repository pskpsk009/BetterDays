# MyGrowth Backend

Placeholder for future backend services.

Device-facing code belongs in `frontend/`: GPS, accelerometer, pedometer,
maps, and trail drawing all require the phone's native APIs. This backend
should receive completed sessions only when persistence or synchronization is
needed.

No API or database is wired yet. The frontend currently uses local mock data and simulated movement tracking.

Planned areas:

- User profiles and settings
- Mental and body activity persistence
- Movement trail/session storage
- Authentication and API validation
