# Before / After - Every MUST Task

Real-user sessions, 2-3 November 2026 (REAL, U01-U06), copied from
`session-logs.md`. Targets come from `../test-plan.tex` Section 5.

- **Before** = the participant's usual way, without BetterDays.
- **After** = the same task in BetterDays.
- T3-T5 have no usual-way equivalent, so they are compared against the
  test-plan target.
- **Not recorded** values are left out of medians. "0 s" (U04, T4 and T5) is
  not a valid time and is also left out.
- Read with the data notes at the end of `session-logs.md` (screening answers,
  missing values).
