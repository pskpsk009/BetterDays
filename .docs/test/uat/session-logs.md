# Session Logs - Real-User Testing

Real sessions, 2-3 November 2026, copied from the filled-in
`real-user-session-form.docx`. Values are copied exactly as written on the
forms. **Not recorded** = the box was empty on the form. Codes only, no names.

**Data notes (see the end of this file):** some boxes were empty or unclear
on the forms, and all six participants answered Yes to a screening question
that the test plan uses to exclude people. These are reported, not changed.

Task scenarios and success rules: `README.md`. Severity scale (Nielsen):
0 not a problem, 1 cosmetic, 2 minor, 3 major, 4 catastrophe.

**Rules for every session (test-plan.tex Section 4):**

- Participants type made-up text only, never their real feelings or history.
- All of the participant's test data is deleted at the end of the session.
- If a participant becomes upset, stop, share the support information, and
  mark the session "Counted: No".

**How to measure (test-plan.tex Section 5):**

| Task | Time | Taps |
|---|---|---|
| T1 Calm down | End of scenario to activity running | From Home |
| T2 Sleep times | End of scenario to targets saved and night logged | Not counted |
| T3 Backup | Start of T3 to backup on (setup time) | Not counted |
| T4 Find help | End of scenario to help on screen | From Home |
| T5 Export and delete | End of scenario to deletion confirmed | From Profile, before the final confirmation |

Errors = wrong tap, dead end, or asked for help.
