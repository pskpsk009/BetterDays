# Role Statement - Thura Min Tun (6631503095)

**Role:** Project Owner and Frontend Developer

For this project, I made the product vision, scope, objectives and weekly plan for better days. I built for project charter and requirement specification, created the repository and documentation and kept the project objective and scope, wellbeing activities which follow our privacy and safety rules as in ‘rule.md’. In the work logs I recorded important product changes and kept the README really clear for reviewers and for the new team members.  Being a front-end developer, I made the Expo mobile application and most of the better days app screens. I built the home screen with a really well interactive figure which can make open mind, body and trail, and after adding the question “What do you need right now” finder and the welcome guide. I also created a profile sheet where users can log into it, turn on backup, download their data, or remove it. In conclusion, consistency for keeping on a large set of screens and easy to use on small phones was my main challenge.
